# Templates

| File | Use for |
|------|---------|
| `work-item/` | Copy to `2-work/<name>/` for a new product, project or repo. |
| `adr.md` | A decision record: copy into an item's `decisions/` as `adr-NNN-<slug>.md` (or use `kb-decide`). |
| `skill/` | Copy to `.claude/skills/<name>/` (here, in a repo, or in `~/.claude/skills/`). |
