# Templates

| File | Use for |
|------|---------|
| `work-item/` | Copy to `2-work/<name>/` for a new project, product, repo or area. |
| `system.md` | A page in `4-know/systems/`: a service, app, database or pipeline. |
| `person.md` | A page in `4-know/people/`: someone you work with (work facts only). |
| `concept.md` | A page in `4-know/domain/`: a term that means something specific here. |
| `playbook.md` | A page in `4-know/playbooks/`: a task you repeat, step by step. |
| `incident.md` | A page in `4-know/incidents/`: what broke, why, what changed. |
| `adr.md` | A decision record: copy into an item's `decisions/` as `adr-NNN-<slug>.md` (or use `kb-decide`). |
| `skill/` | Copy to `.claude/skills/<name>/` (here, in a repo, or in `~/.claude/skills/`). |

Every page shares one header: `type`, `status`, `owner`, `updated`, `review`, `data`, then a
**Purpose** and a **Not here** line. `0-meta/conventions.md` says what each means.
