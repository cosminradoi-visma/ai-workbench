# Writing KB pages

<!-- Path-scoped rule: loads only when one of these files is read. Full rules: 0-meta/conventions.md -->

- `state.md` and `NOW.md` are snapshots: overwrite them. History goes to the item's `log.md`.
- Limits: `NOW.md` ≤ 40 lines, `state.md` ≤ 80, `profile.md` ≤ 30. Split rather than grow.
- Set `updated:` to today on any page you change. Mark unconfirmed claims `[unverified]`.
- New file? Add its line to the folder's `README.md`.
- Write what an agent would get wrong; skip what it can read from the code.
- No secrets, personal data, or customer/payroll records. Ever.
