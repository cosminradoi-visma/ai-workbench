# Playground

A safe place to try to make your own agent leak. Everything here is fake. Open Claude Code in your
workbench (`cd ~/workbench && claude`); the workbench's own `.claude/settings.json` is what stops it.

| File | What it is |
|------|------------|
| `TRY.md` | Four things to try, what to predict, and what should happen |
| `.env` | A fake secrets file. The agent may not read it |
| `config.yaml` | A fake config with a fake password inside: the honest miss |
