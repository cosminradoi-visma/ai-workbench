# 1-me: true across all your work (private)

| File | What it is |
|------|------------|
| `profile.md` | Who you are and how agents should work with you. Read every session. |
| `how-i-work.md` | How you think and decide: heuristics, quality bar, trade-offs you usually make. |
| `team.md` | People, who owns what, who to ask: one line each. Someone you work with often gets a page in `4-know/people/`. |
| `glossary.md` | Internal terms, acronyms and system names, one line each. A term that needs more links to its page in `4-know/domain/` or `4-know/systems/`. |
| `learnings.md` | Gotchas and lessons that apply beyond one work item. |
| `brag.md` | What you did and what it changed, for reviews. Drafted from the logs every two weeks. |
