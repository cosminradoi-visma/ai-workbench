# Archive

Finished or dropped work items move here, so they leave `NOW.md` and the read path but stay
searchable. Stale pages next to live ones mislead an agent; they don't just cost tokens.

To archive: set `status: done` (or `dropped`) on the card, write the three-line **Outcome** at the
top of `state.md` (what shipped, what it taught, where the lasting knowledge went in `4-know/`), move
the folder here, and move its row from `2-work/README.md` to the table below. `kb-tidy` offers this.
