# 2-work: projects, areas, products and repos (private)

One folder per thing you work on. Start one with `kb-setup`, `kb-link-repo`, or by
copying `0-meta/templates/work-item/`.

- **project:** ends (a feature, a migration). When it does, it moves to `_archive/`.
- **area:** never ends (on-call, a service you own, your team, hiring). It stays, and its
  state page is what is true now.
- **product** / **repo:** long-lived things you build, usually with a linked code repo.

What you learn along the way goes to `4-know/` (systems, people, concepts, playbooks, incidents),
so it outlives the item. Finished items: [`_archive/`](_archive/README.md).
